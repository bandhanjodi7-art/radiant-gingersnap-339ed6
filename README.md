# BandhanJodi — Matrimony Platform

A mobile-first matrimony / marriage bureau web app based on the BandhanJodi design.

**Tech:** TanStack Start (React 19), Tailwind CSS 4, Netlify Database (Postgres + Drizzle ORM), Netlify Identity, deployed on Netlify.

## Run locally
```bash
pnpm install
netlify dev
```
